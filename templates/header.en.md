# Awesome Social Media Skills

[中文](README.md) · **English**

> A curated list of agent skills for social media: X, YouTube, TikTok, Instagram and LinkedIn, plus China's Xiaohongshu (RedNote), Douyin, WeChat and Bilibili. From ideas and drafts to images, publishing and analytics. Install them into Claude Code, Codex, OpenClaw, Qwen, Doubao or WorkBuddy.

This list collects social media skills for AI agents: writing posts and threads, making covers and short videos, scheduling, tracking trends, replying to comments and reading analytics. Most use the standard SKILL.md format, so any agent that supports skills can install them; see the [FAQ](#faq). Every project was checked by hand and scanned by a script before it was listed, and is sorted by job and platform.

Many projects come from China's creator scene (Xiaohongshu, Douyin, WeChat Official Accounts) and are documented in Chinese; the descriptions below are translated.

> [!WARNING]
> Tools that post or reply for you usually log in as you, and some keep your cookies on disk. Read the SKILL.md and scripts before installing to see where your session is stored and where it is sent. Platforms limit automation; bulk posting can get an account throttled or banned.

> [!NOTE]
> "Checked by hand" means the README, directory structure and classification were reviewed; it does not mean the output was tested. The script scan looks for binaries and archives, install hooks, remote code execution and reads of sensitive files, and lists the network addresses in scripts. A clean scan does not prove a skill is safe.
